# 👮 Staff Permissions

## Head Moderator

- All Senior Mod permissions
- Can **unban users**
- Can **set nicknames**
- Can **approve reports and submissions**

### Limits
- Cannot manage roles
- Cannot manage server
- Cannot modify admin systems

---

## Summary

> Head Moderator = Senior Mod + unban + setnick + approvals
